# Contributing to UltraShape Mac

Thanks for your interest in contributing. Here is how to get started.

## Reporting Issues

Open an issue with:
- Your hardware (Mac model, chip, memory)
- Python and PyTorch versions
- Steps to reproduce the problem
- Full error output

## Pull Requests

1. Fork the repo and create a branch from `main`
2. Make your changes
3. Test on Apple Silicon if possible
4. Open a PR with a clear description of what changed and why

## What We Need Help With

- Testing on different Mac configurations (M1, M2, M3, M4 with varying memory)
- Performance optimizations for MPS
- Better memory management and OOM handling
- Documentation improvements
- Support for additional input formats

## Code Style

- Follow the existing code conventions
- Keep changes focused -- one fix or feature per PR
- Add comments for non-obvious MPS workarounds
